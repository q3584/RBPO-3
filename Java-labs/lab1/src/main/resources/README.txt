Назначение программы
Приложение автоматизирует учет садовой деятельности: позволяет управлять пользователями, планировать размещение культур на грядках с учетом свободной площади, отслеживать процесс посадки и фиксировать сбор урожая.

Реализованные бизнес-сущности (CRUD):
User (Пользователь): владелец сада или дачного участка.
Crop (Культура): растение или овощ с указанием минимальной требуемой площади и сезона посадки.
GardenBed (Грядка): участок земли с определенной площадью и статусом доступности.
Planting (Посадка): процесс высадки определенного количества растений на конкретную грядку.
Harvest (Урожай): фиксация сбора урожая с регистрацией массы.

Реализованные бизнес-операции:
Проверка площади при посадке: автоматический расчет требуемой площади на основе количества растений и проверка доступности пространства на выбранной грядке с последующим изменением статуса грядки на занятую.
Автоматическое освобождение грядки при сборе урожая: фиксация сбора урожая с проставлением текущей даты и автоматическим переводом грядки обратно в статус свободной для новых посадок.
Управление статусом грядки при посадке: автоматическое переведение грядки в статус занятой при успешном создании посадки.
Автоматическая фиксация даты сбора урожая: автоматическая генерация и сохранение текущей даты при регистрации сбора урожая.
